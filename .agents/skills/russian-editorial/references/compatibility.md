# Разделение ответственности: Russian Editorial, Sasha, Humanizer.ru

Основной источник: предоставленный архив `russian-editorial(1).zip`, раздел `references/compatibility.md`.

| Задача | Основной навык |
|---|---|
| Разработать новый текст, смысл, структуру, тезисы и подтверждения | `$russian-editorial` / write или edit |
| Оценить качество аргументации без правок | `$russian-editorial` / audit |
| Написать интерфейсные кнопки, подписи, FAQ, ошибки и подсказки | `$sasha` |
| Убрать канцелярит и шаблонность без перестройки смысла | `$humanizer-ru` |

Не запускать несколько навыков автоматически. Humanizer не вправе менять степень уверенности, выдумывать факты или переписывать уже утверждённое УТП. Корректные конструкции не удалять из-за формального совпадения с паттерном. Вычитать утверждения после стилистической правки.
