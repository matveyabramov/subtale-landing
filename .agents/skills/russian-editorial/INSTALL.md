# Установка и использование

Проверено по официальной документации OpenAI 12.11.2026:
[Build skills](https://learn.chatgpt.com/docs/build-skills).
Формат: [Agent Skills specification](https://agentskills.io/specification).

## ChatGPT

В текущей среде ChatGPT Work персональный скилл сохраняется в каталоге навыков. После успешной установки открыть его карточку в разделе Skills; если список не обновился, переоткрыть страницу. Вызов: выбрать `@russian-editorial` и указать задачу/режим.

В разных приложениях и рабочих пространствах доступность персональных скиллов различается. Наличие папки или загруженного в чат SKILL.md само по себе не устанавливает навык во всех версиях ChatGPT. Для переноса использовать доступный в целевой среде механизм Skills; для распространения на другие поверхности может потребоваться плагин. Этот комплект не публикуется.

## Codex CLI / IDE

Перенести всю папку, сохранив относительные пути. Локальная установка для всех проектов:

```bash
mkdir -p ~/.agents/skills
cp -R /path/to/russian-editorial ~/.agents/skills/russian-editorial
```

Для одного проекта положить папку в `.agents/skills/russian-editorial`. Не создавать дубликаты с тем же именем в нескольких областях без необходимости.

Проверить наличие `SKILL.md`, `agents/openai.yaml` и `references/`. Найти навык через `/skills` или вызвать `$russian-editorial`. Путь `/path/to/russian-editorial` в примере заменить фактическим расположением папки.

## Примеры вызова

- `@russian-editorial write: Напиши первый экран. Аудитория… Факты…`
- `@russian-editorial edit: Усиль аргументацию, сохрани голос и ограничения…`
- `@russian-editorial audit: Оцени полезность и доказательства. Не переписывай…`
- В Codex заменить `@` на `$`.

Для одной чистки стиля выбрать Humanizer.ru. Для совместного запроса указать: «Сначала содержание через russian-editorial, затем одна стилистическая вычитка через Humanizer.ru; сохранить корректные конструкции и все существенные утверждения».

## Проверки

Основная работа не требует Python, API-ключа, сетевого доступа, Google Drive или установленного Humanizer.ru: справочники самодостаточны. Проверка фактов и создание файлов требуют соответствующих инструментов только по задаче.

Тестовые материалы не загружать при обычной редактуре. Структурную проверку запустить:

```bash
python3 tests/validate_structure.py
```

Она проверяет комплект, а не литературное качество. Для поведенческого сравнения использовать tests/PROTOCOL.md и новые независимые ответы. Установка в персональном каталоге ChatGPT и перенос в локальный Codex — отдельные операции; успешное сохранение здесь не доказывает установку на компьютере пользователя.
