# SUBTALE — Landing & Wireframe

Единый репозиторий лендинга SUBTALE: редактируемый низкодетализированный wireframe и будущий финальный сайт.

## Просмотр

Откройте `wireframe/index.html` или запустите локально:

```bash
python3 -m http.server 8000
```

Сейчас `/` перенаправляет на `/wireframe/`. В будущем корневую страницу займёт финальный лендинг; прототип останется доступен отдельно.

## Структура

```text
subtale-landing/
├── index.html                # временный переход на /wireframe/
├── wireframe/
│   ├── index.html            # текстовый прототип / 9 секций
│   └── wireframe.css         # монохромный responsive UI
├── docs/
│   ├── structure-v2.1.md     # смысловая структура и ограничения
│   └── figma-references.md   # ссылки на библиотеки и принципы
├── AGENTS.md                 # правила для Codex
├── CODEX_TASK.md             # задание для следующей итерации
└── README.md
```

## Важно

Это учебный концепт, не запущенный продукт. Тексты — черновые, автопоиск скрытых смыслов пока исследовательская гипотеза. Не придумывать отзывы, показатели, тарифы или подтверждения интеграций.

Использовать `CODEX_TASK.md` как отправную точку для Codex. GitHub Pages не включать без отдельного решения: репозиторий приватный.
